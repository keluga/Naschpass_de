# Naschpass_de

Folien für @naschpass_de – Süßigkeiten aus aller Welt.

- `fertige_posts/` – fertige Karussells (JPG) und Captions, nach Post-Nummer
- `THEMEN.md` – Themenliste mit Status
- `generator/` – macht aus `posts.json` die Folien (Windows: `START.bat`)
- `NEUE_POSTS_PROMPT.md` – Prompt für neue Posts per Hand
- `tracking.csv` – Zahlen nach 48 Stunden eintragen
